SVG, PNG, Escher and optional SBML Layout use a shared route geometry. The E. coli core full FBA viewer adds all source participants and optimizes added branches separately, so its counts differ from the structural drawing.

This is a time-limited local search, not a proven global minimum. Existing line overlaps and node passages remain in these examples and are reported in each drawing's validation report; candidate changes do not introduce new ones.

--routing-objective crossings-first is the default. Use --routing-objective sum for crossings + bends, or --routing-objective weighted --crossing-weight 10 --bend-weight 1 for weighted costs. Use --routing-time-limit 20 to set the search budget and --no-routing-node-moves to keep nodes fixed.
