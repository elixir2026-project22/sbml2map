Orange: undirected paths connecting main pathways to exchange (EX) reactions. The layout minimizes total path length, counting shared branches once. Gray: other branches. Only EX reactions use the outer grid boundary. Filters may hide parts of these paths.

Inorganic compounds are hidden. Red: main pathways (glucose exchange, glycolysis, pyruvate oxidation, TCA). Red pathways come first, followed by orange connectors, then other reactions. Each group is sorted by absolute median flux. Squares: reactions. Circles: compounds. Small gray circles: cofactors. Arrows follow the sign of median flux.

The slider filters the saved layout. To calculate a new layout, run the CLI with --coverage.
