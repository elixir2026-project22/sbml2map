赤とオレンジの交差は、交差なしでは線が2倍以上の長さになる、4グリッド以上余計に迂回する、または交差なしの経路がない場合に許可します。重なりではなく点で横切ります。交差なし・交差ありの長さを接続ごとに保存して検証します。赤同士の交差禁止は維持します。

TCA回路の直径は約12.75から約8.49グリッドへ縮小しました（約2/3）。18ノードを円周上に保ち、各ノードのx座標またはy座標を整数に合わせます。接続の多いTCAノードには格子点を選びます。TCA回路自体の円弧はグリッド配線の例外として残します。四角形も選択できます。

TCAと無関係な線は輪郭の内外とも1グリッド以上離します。実際にTCAノードへ接続する最初の直線部分だけを例外とし、反対側の輪郭への再接近や、輪郭沿いの近接配線は許可しません。TCA内部配置の許可と、交換反応の直線38区間、全色の外周外への配線禁止も維持しています。

多数の線が集まるノードでは記号内に接続口を分けます。ノード中心から接続口への短い部分は記号に覆われます。重なり検証では記号内の接続と記号外の配線を区別し、両方の値を記録します。今回、円形のオレンジの生の重なり長も0、四角形は記号内0.5グリッド・記号外0です。

混雑を解消する間隔を確保した後、使わない外周余白は再配線と検証が通る場合に縮小します。fru_eの上方配置も維持しました。SVG・PNG・Escher・SBMLは同じ接続を使い、保存された全253接続を照合しています。112件のテストが通過しています。

既定の配線モードは--crossing-policy adaptive-gridです。従来の赤交差禁止モードは--crossing-policy red-hardで選べます。TCA内部を禁止する場合は--tca-interior forbidを指定します。有限探索のため、配線長や面積の大域最適は保証しません。
