The layout compares red routes first, including detours and curved TCA connections. It keeps the best valid red layout while adding the other nodes and routes. In all four examples, the chosen red nodes and routes remain unchanged.

If the fixed red layout cannot meet all rules, the program first tries changes with the same red length. It tries longer red routes only when needed and records the reason. The search checks a limited set of candidates, so it does not prove a global minimum.

Node and line rules

Nodes of the same type use the same size, including pyr_c and accoa_c. All nodes except TCA nodes and cofactors sit on integer grid intersections. Cofactors are placed near their reactions and may be off the grid.

Branches at a common node may overlap within 0.5 grid units of its center. Lines of any color cannot run in parallel less than one grid unit apart for two or more grid units. Short branches are allowed without a fixed limit on their number.

The TCA cycle keeps its clockwise reaction order in both shapes. The circular TCA has 18 nodes, a diameter of about 8.49 grid units, and curved cycle connections. Other nodes may be inside the cycle. Unrelated lines stay at least one grid unit from its outline. Connections to the cycle may use short outward branches near their TCA node.

Red and orange lines may cross at a point if avoiding the crossing would at least double the length, add four grid units, or leave no valid route. The reason is recorded. Required straight exchange routes are placed before free routes.

The right and bottom edges are shortened where the rules allow. Labels are moved to avoid overlap, and margins include text and arrows. SVG, PNG, and Escher use the same routes.
